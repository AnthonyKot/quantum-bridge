Chapter 09

Teleportation and dense coding, step by step

A Bell pair supports two different communication protocols. Tracking every register shows where the message resides and why the classical and quantum transmissions are necessary.

Fix the Bell-state convention

Use the four orthonormal states

$$|\beta_{ab}\rangle=(I\otimes X^bZ^a)|\Phi^+\rangle,\qquad a,b\in\{0,1\}.$$

Thus $\beta_{00}=(|00\rangle+|11\rangle)/\sqrt2$, $\beta_{01}=(|01\rangle+|10\rangle)/\sqrt2$, $\beta_{10}=(|00\rangle-|11\rangle)/\sqrt2$, and $\beta_{11}=(|01\rangle-|10\rangle)/\sqrt2$. The order in $X^bZ^a$ means $Z^a$ acts first.

The preparation circuit $\operatorname{CNOT}(H\otimes I)$ maps $|ab\rangle$ to $|\beta_{ab}\rangle$. Its inverse, CNOT followed by $H$ on the first qubit, maps each Bell state to its two-bit label. A Bell measurement can therefore be implemented by that inverse circuit followed by ordinary computational-basis measurements.

Teleportation: three registers and one unknown input

Alice holds an unknown input $Q$ in $|\psi\rangle=\alpha|0\rangle+\beta|1\rangle$ and one half $A$ of a shared Bell pair. Bob holds the other half $B$. In register order $Q,A,B$, the initial state is

$$|\psi\rangle_Q|\Phi^+\rangle_{AB}=\frac1{\sqrt2}\left(\alpha|000\rangle+\alpha|011\rangle+\beta|100\rangle+\beta|111\rangle\right).$$

Alice applies CNOT from $Q$ to $A$. The four terms become $\alpha|000\rangle+\alpha|011\rangle+\beta|110\rangle+\beta|101\rangle$, with the same factor $1/\sqrt2$. To apply $H$ to $Q$, replace the leading $|0\rangle$ in each term by $(|0\rangle+|1\rangle)/\sqrt2$, and each leading $|1\rangle$ by $(|0\rangle-|1\rangle)/\sqrt2$. The existing factor $1/\sqrt2$ combines with this new one to give $1/2$. Before collecting any terms, the result is

$$\begin{aligned}\frac12\big(&\alpha|000\rangle+\alpha|100\rangle +\alpha|011\rangle+\alpha|111\rangle\\ &+\beta|010\rangle-\beta|110\rangle +\beta|001\rangle-\beta|101\rangle\big). \end{aligned}$$

Now group terms by the first two bits, since those are the registers Alice measures. Prefix $00$ occurs in $\alpha|000\rangle+\beta|001\rangle$, leaving Bob's vector $\alpha|0\rangle+\beta|1\rangle$. Prefix $01$ occurs in $\beta|010\rangle+\alpha|011\rangle$, leaving $\beta|0\rangle+\alpha|1\rangle=X|\psi\rangle$. The other two prefixes work the same way:

$$\begin{aligned} 10:&\quad \alpha|0\rangle-\beta|1\rangle=Z|\psi\rangle,\\ 11:&\quad -\beta|0\rangle+\alpha|1\rangle=XZ|\psi\rangle. \end{aligned}$$

This is a regrouping of the same eight terms, with no measurement yet performed. It puts the joint state in a form where each possible result on Alice's side has an explicit conditional vector on Bob's side:

$$\frac12\Big[|00\rangle|\psi\rangle+|01\rangle X|\psi\rangle+|10\rangle Z|\psi\rangle+|11\rangle XZ|\psi\rangle\Big].$$

Each bracketed Bob vector has norm one, so every two-bit outcome occurs with probability $1/4$, independently of $\alpha,\beta$. If Alice obtains $(a,b)$, Bob holds $X^bZ^a|\psi\rangle$. Alice sends the two classical bits; Bob applies the inverse $Z^aX^b$, meaning $X^b$ first and then $Z^a$.

What Bob has before the message arrives

Without Alice's bits, Bob must average over the four outcomes. For any input density matrix,

$$\rho_B=\frac14\sum_{a,b}X^bZ^a\rho Z^aX^b=\frac I2.$$

To check it, expand $\rho=(I+r_xX+r_yY+r_zZ)/2$: conjugation by the four Paulis cancels each Bloch component. Bob's local state contains no dependence on the unknown input until the classical record permits correction. Teleportation therefore cannot signal faster than the classical channel.

After Alice's measurement, her input register has a definite computational-basis value; it no longer carries $|\psi\rangle$. The shared Bell pair is consumed. The amplitude pair $\alpha,\beta$ survives in Bob’s corrected register, while Alice’s measured registers contain only the two random outcome bits. There is no second remaining register in state $|\psi\rangle$, which is why this transfer is compatible with the no-cloning theorem. Moreover, the protocol preserves entanglement with an external reference: expand a joint input as $\sum_jc_j|j\rangle_R|\psi_j\rangle_Q$ and apply the same identity term by term. Every corrected branch transfers that joint state from $RQ$ to $RB$.

Dense coding: encode a classical label in a Bell state

Now Alice and Bob share $|\Phi^+\rangle$, and Alice wants to transmit two classical bits $(a,b)$. She applies $X^bZ^a$ to her qubit and sends that qubit to Bob. Moving a matrix across this Bell state transposes it: $(M\otimes I)|\Phi^+\rangle=(I\otimes M^T)|\Phi^+\rangle$. To see this, write $|\Phi^+\rangle=\frac1{\sqrt2}\sum_j|j\rangle|j\rangle$; then $\sum_j M|j\rangle|j\rangle=\sum_{i,j}M_{ij}|i\rangle|j\rangle=\sum_i|i\rangle\sum_j (M^T)_{ji}|j\rangle=\sum_i|i\rangle\,M^T|i\rangle$. For these Paulis the transpose changes at most a global sign, so the joint state is $|\beta_{ab}\rangle$ up to phase.

Bob now possesses both qubits and uses the Bell-decoding circuit to read $a,b$ with certainty. This transmits two classical bits using one transmitted qubit and one previously shared Bell pair. Both resources belong in the statement.

Each transmitted-qubit state on its own is $I/2$, for all four messages. An observer holding only that qubit learns zero bits about the chosen label, not one. The information is in joint correlations with Bob's retained qubit. Chapter 15 will calculate this using the Holevo quantity.

Problems

1. Teleport $|\psi\rangle=(|0\rangle+i|1\rangle)/\sqrt2$ in the branch $(a,b)=(1,1)$. Verify the correction.

Worked answer

First apply $Z$ and then $X$, in the order specified by $XZ$:

$$\frac{|0\rangle+i|1\rangle}{\sqrt2}\xrightarrow{Z}\frac{|0\rangle-i|1\rangle}{\sqrt2}\xrightarrow{X}\frac{|1\rangle-i|0\rangle}{\sqrt2}.$$

Bob’s inverse $ZX$ means applying $X$ first. That gives $(|0\rangle-i|1\rangle)/\sqrt2$; applying $Z$ then gives $(|0\rangle+i|1\rangle)/\sqrt2$, the input. The algebraic check is $ZX\,XZ=Z(X^2)Z=Z^2=I$. The two noncommuting factors must be reversed when taking the inverse.

2. Alice sends only the bit $b$, so Bob corrects $X^b$ but does not know $a$. What channel remains?

Worked answer

After Bob corrects $X^b$, his state is $Z^a\rho Z^a$. The unreported bit $a$ is still equally likely to be zero or one, so he must average these two possibilities. Write the input in matrix form and multiply:

$$Z\rho Z=\begin{pmatrix}\rho_{00}&-\rho_{01}\\-\rho_{10}&\rho_{11}\end{pmatrix},\qquad\frac{\rho+Z\rho Z}{2}=\begin{pmatrix}\rho_{00}&0\\0&\rho_{11}\end{pmatrix}.$$

The diagonal entries survive, while the off-diagonal terms cancel. Input $|+\rangle$ therefore becomes $I/2$, whereas $|0\rangle$ remains $|0\rangle$. The missing bit matters for restoring arbitrary coherence, even though it does not matter for a computational-basis input.
